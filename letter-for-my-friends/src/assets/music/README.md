# Music

One background track per friend, named to match their `music.src`
field in `src/data/friends.js`:

```
samya.mp3
saniya.mp3
shafin.mp3
shobanaa.mp3
shanofar.mp3
roshini.mp3
```

Each friend also has an optional `music.label` (e.g. a song title)
shown as a small caption next to the player controls.

Music starts automatically once the envelope opens and the letter
appears — not before. Keep tracks soft/instrumental so they don't
compete with the typewriter reveal.
