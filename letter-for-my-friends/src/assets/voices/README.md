# Voice Notes

One optional recorded voice message per friend, named to match
their `voiceNote.src` field in `src/data/friends.js`:

```
samya.mp3
saniya.mp3
shafin.mp3
shobanaa.mp3
shanofar.mp3
```

Roshini has `voiceNote: null` — the Voice Message page and its nav
button are skipped entirely for her. To skip a page for any other
friend, set their `voiceNote` to `null` as well.

Keep clips short (15–60s), mp3 or m4a.
